# Yoru

> A small personal portfolio website.

This is my personal portfolio website where I keep some of the projects I've built and a little bit about me.

I wanted something simple, clean and not overloaded with random animations or stuff that doesn't really need to be there.

## ✦ What is Yoru?

Yoru is basically my little corner of the internet.
The design is intentionally pretty minimal. I like interfaces that are clean and actually let the content breathe.





## 🚀 Projects

A few things currently on the site:

### Web OS
A web-based OS style interface that I made mostly because I wanted to experiment with making a desktop-like experience inside a browser.

**Live:** https://web-os-1-rho.vercel.app/

### Orank Tab
A custom browser start page / tab focused on making the browser home screen more useful and personal.

**Live:** https://orank-tab.vercel.app/

### LLM
A small language model project that I built while learning more about how LLMs work under the hood.

**Repository:** https://github.com/aniway89/LLM

## 🛠️ Built With

Nothing complicated here.

- HTML
- CSS
- A lot of messing around with the design

The current version is intentionally lightweight and doesn't need a huge framework just to display a portfolio.

## 🎨 Design

I wanted the website to feel:
- Simple
- Clean
- Minimal

The UI is mostly based around typography, spacing and a lot of empty space.


Note: This website is build by me form scratch no AI is used even a single bit.
